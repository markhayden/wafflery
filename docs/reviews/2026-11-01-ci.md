# CI checkpoint

Branch `ci-macos`, based on `2a3976d`; scope and rollback in [the CI plan](../plans/ci.md).

## Implemented

`.github/workflows/ci.yml` runs on pull requests, pushes to main and manual dispatch using
`macos-15`. All four external actions are pinned to full upstream commit IDs. Node 22.13.1,
Bun 1.4.3 and the toolchain declared in `rust-toolchain.toml` match the checked local setup.
Cargo downloads/builds and Bun's package cache are cached with platform/version/lockfile keys.
Playwright installs matching Chromium/WebKit browsers explicitly, including platform dependencies.

The workflow runs every PLAN command and the two asset-tooling tests. `check-ui.ts` runs before
any regeneration, and a final diff checks that embedded assets and lockfiles stayed unchanged.
Repository permissions are read-only; checkout does not persist credentials. There is no privileged
pull-request trigger, provider secret, deployment, publication or automatic browser-trace upload.
Obsolete concurrent runs cancel and the job has a 45-minute limit. Optional real-tool probes need
explicit local binaries; CI never fetches or builds sibling repositories.

## Verification

- actionlint 1.7.7: valid workflow, expressions, runner label and action inputs. Each shell step
  also passes `bash -n`; ShellCheck is not installed locally.
- Full local matrix run with `CI=true`: fmt, Clippy all targets/features with warnings denied,
  72 Rust tests, TypeScript checks, 12 UI unit tests, two asset-tooling tests, Storybook, browser
  installation, 70 browser cases, reproducible UI assets and release build passed.
- Three Rust probes are ignored by default and four real-tool browser cases skipped as intended;
  these are the existing opt-in checks, not new omissions or disabled required tests.
- Two clean UI builds match committed assets byte-for-byte; lockfiles/generated files unchanged.
- Read-only review approved the workflow's coverage, ordering and public-repository boundaries.

This is local command validation on the development Mac, not evidence of a hosted macOS 15 run.
The coordinator will push and watch that first run. Branch protection was not changed; configuring
required checks remains a repository-owner operation after the status check exists.

No application behavior, dependencies or shared contracts changed. No pushes or tags were made.
