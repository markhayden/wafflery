# M1 checkpoint: local host, sessions and image library

Status: complete. Implementation reviewed through `32a618b` on `feat/m1-local-host`. F05a–F08b are implemented;
M2/M3 and real tool integration are still pending. No paid calls, sibling edits, remote pushes,
installer downloads or provider credentials were used.

## Working behavior

- The default launcher starts or attaches to a detached loopback host. Two simultaneous
  launchers converge; the host survives launcher exit. A lifetime OS lock owns the library.
  Private discovery records locate the socket even when launchers have different TMPDIR values.
  Stale sockets are removed only under the lock; incompatible host identities are refused.
- A private one-use, 60-second bootstrap becomes a host-lifetime browser bearer session.
  The browser removes the fragment before the exchange and stores its session only in
  sessionStorage. Exact Host/Origin checks, no cookie authority, no CORS and CSP apply.
- One bounded worker owns bundled SQLite. Numbered migrations run transactionally, with a
  backup before changes to a populated database. Newer/invalid revisions are refused.
- PNG/JPEG imports copy, fingerprint, decode and publish immutable owned bytes before recording
  references. Identical bytes share storage. Original files are untouched. Reads verify saved
  bytes; corrupted assets are never silently overwritten. Uploads are streamed and bounded.
- The reusable image input supports ordered arrays, explicit cardinality, keyboard reordering,
  removal, errors and Blob URL cleanup. Single-image inputs still enforce one slot. Saved
  images can be selected after a host restart. This does not add list slots to contract v0.1.

## Review corrections and limits

The five-axis review checked correctness, module boundaries, readability, authentication/file
handling and bounded work. It found and corrected these issues:

1. `no-referrer` made WebKit send `Origin: null` for the same-origin POST. The policy is now
   `same-origin`; exact origin validation remains. See the
   [Fetch Origin algorithm](https://fetch.spec.whatwg.org/#append-a-request-origin-header).
2. A socket derived from each launcher's TMPDIR prevented attachment across environments.
   An atomic, private discovery record now locates the socket; the live handshake still proves
   identity. No PID in a file authorizes termination.
3. A negative database revision could reach migration indexing. It now produces a typed error.

F08b exceeded its approximate five-file budget: the component required CSS, typed asset bindings,
Storybook/fixture coverage and App/browser integration. It remained one image-input change
(about 300 added lines excluding generated bytes), but future slices should budget that wiring
explicitly. Generated UI bytes and dependency lockfiles were reviewed separately.

Idle shutdown works through authenticated/private APIs. Active tool shutdown, retention cleanup,
run history and executable tool registration belong to the later approved tasks. The saved-image
list is capped at the most recent 100 imports. No CLI installer or tool-specific UI is implemented.
